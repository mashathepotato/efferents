# Challenge ingestion

**Input:** the text of one public Challengescape challenge card (paste it —
the site is a JS app; capture title, description, POC, domain manually).

**Output:** `labs/lab_NN_<slug>/challenge.md` following
`templates/challenge.md`: verbatim challenge title (quoted, attributed,
linked), the bottleneck restated as one falsifiable framing, first
experiment, dataset + public substitute, metric, and what the lab
expects to exchange with its sibling labs.

**Success criteria:** no claim beyond the source text; the POC's name only
included if publicly listed; the "bottleneck" paragraph is an interpretation
and labeled as this lab's framing, not the challenge author's words.

**Provenance:** link to the challenge page; quote titles exactly.
